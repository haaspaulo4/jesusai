Política de Privacidade

Última atualização: Janeiro de 2025 · Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018)

1. Controlador dos Dados

O controlador dos dados pessoais tratados nesta plataforma é MetaPersona.AI, com sede digital em território brasileiro. Para exercer seus direitos LGPD, entre em contato pelo e-mail: privacidade@metapersona.ai.

2. Dados Coletados

IdentificaçãoNome, e-mail, telefone (opcional), foto de perfil (opcional)
AutenticaçãoSenha (armazenada como hash bcrypt), ID de sessão, token JWT, ID do Google OAuth
Uso da plataformaMensagens de chat, histórico de conversas, persona selecionada, idioma preferido
Perfil e progressoTópicos de interesse, emoções relatadas, jornada pessoal, pedidos de oração, XP, níveis, streaks, badges
CogniçãoAnálise de emoção, intenção, risco de churn, engajamento — gerados automaticamente pela IA
AgentesTarefas, eventos de calendário, contatos CRM, automações, metas, memória organizacional
Bot (WhatsApp/Telegram)ID do WhatsApp, ID do Telegram, mensagens de áudio transcritas, conta vinculada
TécnicoEndereço IP, user-agent, cookies de sessão, rate limit counters

3. Base Legal para Tratamento

Consentimento (Art. 7º, I): Coleta e processamento de dados de perfil, preferências, mensagens de chat e dados de gamificação. Você pode revogar o consentimento a qualquer momento.

Execução de contrato (Art. 7º, V): Processamento necessário para prestação do serviço de chat com IA, armazenamento de histórico, e funcionalidades encomendadas (tarefas, calendário, CRM).

Legítimo interesse (Art. 7º, IX): Análise cognitiva para melhoria da experiência, prevenção de fraude/abuso (rate limiting, ban), e otimização do serviço.

Cumprimento legal (Art. 7º, II): Retenção de dados conforme exigência legal e regulatória.

4. Finalidade do Tratamento

  • Prestação do serviço de agentes cognitivos com IA
  • Personalização da experiência (persona, idioma, progresso, gamificação)
  • Gamificação: XP, níveis, streaks, badges e ranking
  • Análise cognitiva de sentimento, intenção e engajamento para adaptação automática
  • Funcionalidades de agente: tarefas, calendário, CRM, automações, metas
  • Comunicação via WhatsApp, Telegram e interface web
  • Armazenamento de conhecimento (RAG) por persona com busca semântica
  • Melhoria contínua do serviço e prevenção de abuso
  • Envio de e-mails transacionais (confirmação, recuperação de senha, devocionais)

5. Compartilhamento de Dados

Seus dados não são vendidos, alugados ou compartilhados com terceiros para fins comerciais. O compartilhamento ocorre apenas nas seguintes situações:

  • Processadores de IA (Ollama Cloud): Mensagens são enviadas à API para gerar respostas. Dados são processados conforme a política do provedor.
  • WhatsApp Business API: Mensagens enviadas/recebidas via WhatsApp são processadas pela Evolution API e Meta.
  • Telegram Bot API: Mensagens enviadas/recebidas via Telegram são processadas conforme a política do Telegram.
  • Google OAuth: Apenas e-mail e nome são coletados para autenticação. Nenhum dado do Google é armazenado além do necessário para login.
  • STT (Whisper): Áudios transcritos via Groq/OpenAI. Arquivos de áudio não são armazenados.
  • Obrigação legal: Quando exigido por lei, ordem judicial ou determinação de autoridade competente.

6. Armazenamento e Segurança

Localização: Os dados são armazenados em banco de dados MySQL em servidor próprio no Brasil.

Senhas: Armazenadas como hash bcrypt (cost factor 10). Nunca armazenadas em texto plano.

Comunicação: Todo tráfego web é criptografado via HTTPS/TLS.

Autenticação: JWT com expiração de 1 hora + refresh token. Controle de sessão ativo.

Rate limiting: Limites de uso por perfil (guest: 5/dia, user: 30/dia, premium: 100/dia, admin: 999/dia).

Controle de acesso: Role-based (guest, user, premium, admin). Usuários banidos são bloqueados imediatamente.

Retenção: Dados de chat são mantidos enquanto a conta estiver ativa. Dados de rate limiting são limpos a cada 24h.

7. Direitos do Titular (Art. 18 LGPD)

Você pode exercer qualquer um dos direitos abaixo a qualquer momento. Basta acessar Configurações → Meus Dados na plataforma ou enviar e-mail para privacidade@metapersona.ai.

✓Confirmação e acesso — Saber quais dados temos e acessá-los
✓Correção — Corrigir dados incompletos, inexatos ou desatualizados
✓Anonimização — Anonimizar dados desnecessários
✓Portabilidade — Exportar seus dados em formato estruturado (JSON)
✓Eliminação — Solicitar exclusão dos dados pessoais
✓Revogação do consentimento — Revogar consentimento a qualquer momento
✓Oposição — Opor-se a tratamento realizado com base em legítimo interesse
✓Informação sobre compartilhamento — Saber com quem seus dados foram compartilhados

8. Cookies e Tecnologias de Rastreamento

Utilizamos cookies e tecnologias semelhantes conforme detalhado em nossa Política de Cookies. Os cookies essenciais são necessários para o funcionamento do serviço. Cookies de análise e preferência só são ativados com seu consentimento.

9. Menores de Idade

O serviço não é direcionado a menores de 16 anos. Não coletamos intencionalmente dados de menores. Se tomarmos conhecimento de que coletamos dados de menor de 16 anos sem consentimento dos pais ou responsável legal, os dados serão eliminados imediatamente.

10. Transferência Internacional de Dados

Os dados podem ser processados por provedores de IA (Ollama Cloud, Groq, OpenAI) localizados fora do Brasil. Quando isso ocorre, garantimos que a transferência obedece aos requisitos do Art. 33 da LGPD, utilizando cláusulas contratuais padrão e garantias adequadas de proteção.

11. Alterações nesta Política

Podemos atualizar esta política periodicamente. A versão mais recente estará sempre disponível nesta página com a data de última atualização. Alterações significativas serão comunicadas por e-mail ou notificação na plataforma. O uso continuado após a notificação constitui aceitação das alterações.

Para exercer seus direitos ou esclarecer dúvidas sobre tratamento de dados pessoais, entre em contato com nosso Encarregado de Proteção de Dados:

E-mail: privacidade@metapersona.ai

Prazo de resposta: Até 15 dias úteis (Art. 18, §5 LGPD)
